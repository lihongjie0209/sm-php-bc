## 🎯 项目概述

## 🚀 快速开始

### 安装
```bash
composer require sm-php-bc/sm-php-bc
```

### 基本使用
```php
// SM3 哈希
$digest = new SM3Digest();
$digest->updateBytes('Hello', 0, 5);

// SM2 加密
$keyPair = SM2::generateKeyPair();
$ciphertext = SM2::encrypt('secret', $keyPair['publicKey']);

// SM4 加密
$encrypted = SM4::encryptCBC('data', $key, $iv);
```

### 运行示例
```bash
php examples/sm3-hash.php
php examples/sm2-sign.php
php examples/sm4-modes.php
```

### 运行测试
```bash
vendor/bin/phpunit
```

## 🔒 安全说明

### 推荐使用
- ✅ SM2 加密（公钥加密）
- ✅ SM2 签名（数字签名）
- ✅ SM3 哈希（消息摘要）
- ✅ SM4-CBC（需要 IV）
- ✅ SM4-CTR（流密码）
- ✅ SM4-GCM（认证加密，最推荐）

### 不推荐使用
- ⚠️ SM4-ECB（仅用于兼容性测试）
- ⚠️ ZeroByte 填充（特定场景）

### 安全实践
- ✅ 使用安全的随机数生成器
- ✅ 妥善保管私钥
- ✅ 使用足够长度的密钥
- ✅ 定期更新密钥
- ✅ 选择合适的工作模式
